3. Create a ClusterIssuer that uses this shared-account webhook. Example:

   apiVersion: cert-manager.io/v1
   kind: ClusterIssuer
   metadata:
     name: letsencrypt-production
   spec:
     acme:
       email: your-email@example.com
       server: https://acme-v02.api.letsencrypt.org/directory
       privateKeySecretRef:
         name: letsencrypt-account-key
       solvers:
       - dns01:
           webhook:
             groupName: {{ .Values.groupName }}
             solverName: infoblox-wapi
             config:
                view: "Your DNS View"
                ttl: 300
                useTtl: true

4. The existing credentials Secret must contain an ordinary JSON credentials file:
   kubectl create secret generic {{ .Values.infoblox.credentials.existingSecret }} \
      -n {{ .Release.Namespace }} \
      --from-file={{ .Values.infoblox.credentials.key }}=/secure/path/creds.json
